## Classification used (exactly one per row)
| Class | Meaning |
|---|---|
| IMPLEMENTED IN CODE | Present in the repository (code, CDK construct, migration, test). Not proof that it is deployed or that live settings match. |
| DOCUMENTED POLICY/PROCEDURE ONLY | A document or script describes it; no enforcing code, or no evidence it was carried out. |
| UNVERIFIED | Needs live evidence (AWS console/CLI, Netlify, Supabase, GitHub settings, or a person's statement). Older owner-reported results are cited as history, not as current proof. |
| NOT FOUND | Searched for; nothing in the repository. |

Severity if missing: **Critical** = blocks any real-customer data; **High** = must close or be formally accepted before real-customer pilot; **Medium** = close before general availability or accept in writing; **Low** = improvement.
Owner roles: **Owner** (agency owner / Security Official), **Operator** (holder of AWS admin credentials, runs CloudShell), **Eng** (Claude Code / developers), **Legal** (counsel or compliance adviser).
