Created 2026-11-10. Branch `claude/ogevia-ux-audit-redesign-w36cov`, HEAD `e35781d` when this was written.

## Rules for this file
1. Read it at the start of every session, before any build work (pointer in `CLAUDE.md`, section 0).
2. Status is one of: **NOT STARTED**, **IN PROGRESS**, **DONE**, **BLOCKED**. A row is **DONE only with evidence** (commit, test name, screenshot path). Anything partly done stays IN PROGRESS and says what is missing.
3. **Never delete a row.** A row that no longer applies is marked **SUPERSEDED** with the reason and the date.
4. "Verified on demo" is **yes** only after the owner (or an operator) has confirmed the behaviour on demo.ogevia.com. Local tests and screenshots never set it to yes. As of this writing nothing has been deployed to demo, so every row is **no**.
5. Distinguish proposed, implemented, tested, deployed (`CLAUDE.md` section 0). "Implemented locally" is never "deployed".
