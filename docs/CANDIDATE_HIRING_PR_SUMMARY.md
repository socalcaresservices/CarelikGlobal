# Candidate Hiring V1 — Change Summary

This change set is an administrative workflow upgrade. It adds recruiting intake/import, Candidate pipeline tracking, onboarding, credentials, temporary Candidate self-service, and independent workforce records. All hiring-stage and credential-verification changes are explicitly initiated by authorized organization staff; no automated ranking, scoring, recommendation, selection, or rejection is implemented.

The branch must remain unmerged until CI and non-production database/RLS verification are complete and the remaining release blockers documented in `CANDIDATE_HIRING_BUILD_VERIFICATION.md` are resolved.
