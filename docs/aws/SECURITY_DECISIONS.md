# Ogevia — AWS Security Decisions (Phase 0)

**Date:** 2026-09-30 · **AWS changes:** NONE

Using AWS services does **not** make Ogevia HIPAA compliant (`CLAUDE.md` §1, §8). Each control below is the application's responsibility under the shared-responsibility model.

Status legend: **DECIDED** (fixed by `CLAUDE.md`) · **PROPOSED** (default Claude recommends; reversible) · **OWNER DECISION** (legal, financial, or irreversible).

---
