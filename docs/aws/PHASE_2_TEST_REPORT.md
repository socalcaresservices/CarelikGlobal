### Negative controls run during development (not committed as tests)

- With the current-main M-1 behaviour reintroduced (resolution without `is_current`, usage per version ID, cap from the bound version), **11 of 16 authorization tests failed**. With the fix restored, 16/16 passed.
- Injecting `grant … to authenticated; select auth.uid();` into a migration made the static "no Supabase dependency" check fail.
- The harness itself caught two product bugs that were then fixed: `gen_random_bytes` was invisible under the pinned search_path (pgcrypto removed), and the visit guard reported "illegal transition" before "immutable".
