===== SECRETS MANAGER (create with -prd suffix) =====

1. ogevia/database/app-prd
   - Required for: Lambda API database access
   - Contains: {
       "username": "<db_user>",
       "password": "<db_pass>",
       "engine": "postgres",
       "host": "<ogevia-prd-postgres.*.rds.amazonaws.com>",
       "port": 5432,
       "dbname": "ogevia_prd"
     }
   - Access: Lambda assumes role with SecretManagerRead policy

2. rds!db-<uuid>-prd  (RDS master secret - auto-managed)
   - Created automatically by RDS when database is created
   - DO NOT modify, AWS manages this

===== COGNITO (create new app client) =====

3. Cognito User Pool: Create new or reuse us-west-2_849AYz5J7
   
4. Cognito App Client (new, for prd frontend)
   - Name: ogevia-prd-web
   - Type: Public
   - Auth flow: Authorization code + PKCE
   - Allowed callback URLs:
     * https://app.ogevia.com/auth/callback
     * http://localhost:5173/auth/callback (dev only)
   - Allowed logout URLs:
     * https://app.ogevia.com/
     * http://localhost:5173/ (dev only)
   - Generate: Copy Client ID for VITE_COGNITO_CLIENT_ID

===== DEPLOYMENT CHECKLIST =====

Before `cdk deploy` for prd:

[ ] RDS database created: ogevia-prd-postgres
    - Engine: PostgreSQL 15+
    - Instance: db.t3.micro (pilot) → db.t3.small (prd recommended)
    - Encrypted: true
    - BackupRetentionPeriod: 30 days
    - MultiAZ: true (or false for non-prod)
    - DeletionProtection: true
    
[ ] KMS key created for encryption (optional, uses AWS-managed if not specified)

[ ] Secrets Manager secrets created with -prd suffix:
    [ ] ogevia/database/app-prd
    [ ] rds!db-<uuid>-prd (auto-created by RDS)

[ ] Cognito app client created:
    [ ] Client ID noted
    [ ] Callback URLs configured
    [ ] Logout URLs configured

[ ] Environment variables set in:
    [ ] infra/aws/lib/config.ts (Cognito IDs, endpoints)
    [ ] apps/web/.env.production (VITE_* variables)
    [ ] Netlify site settings (STRIPE_*, SUPABASE_*, APP_URL)

[ ] CDK synth successful: `pnpm cdk synth -c env=prd -c mode=plan`

[ ] Ready for deployment: `pnpm cdk deploy -c env=prd --all`
